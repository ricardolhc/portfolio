# AWS logo

`aws-logo.svg` is the Amazon Web Services wordmark and smile, authored by Amazon.com, Inc. Downloaded unchanged on 22 October 2026 from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Amazon_Web_Services_Logo.svg) ([original SVG](https://upload.wikimedia.org/wikipedia/commons/9/93/Amazon_Web_Services_Logo.svg)).

The source lists Apache License 2.0; its text is included in `public/licenses/aws-logo-Apache-2.0.txt`, along with attribution in `aws-logo-NOTICE.txt`. Vite copies these files into the production build. Amazon Web Services and its logo are trademarks of Amazon.com, Inc. or its affiliates. See [AWS trademark guidelines](https://aws.amazon.com/trademark-guidelines/).

The graphic retains its original paths, colors and aspect ratio. It is rendered on a small white background within the certification card, without recoloring, filters or animation. Vite imports and bundles it locally, including when deployed under a GitHub Pages repository path; the browser does not load it from a third party.
